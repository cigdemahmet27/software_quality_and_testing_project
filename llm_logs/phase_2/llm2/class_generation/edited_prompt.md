# Edited & Combined Prompt — BookScan Class Generation (LLM2: Claude)

## Prompt Sent to LLM

Create a Java class called `BookScan` in the package `phase_2.llm2` that analyzes text documents to find word occurrences by length and track their line positions.

### Class Purpose
`BookScan` processes multi-line text (where lines are separated by `\n`) to:
1. Find all words of a specified length in the text
2. Count how many times each such word appears (including overlapping occurrences as substrings)
3. Track which line numbers each word appears on (1-indexed)
4. Support case-insensitive matching by using case transformation

### Required Internal Methods

The class must contain these three utility methods internally (not imported from other classes):

#### 1. `howManyTimes(String text, String substring)` → `int`
- Counts how many times `substring` appears in `text`, **including overlapping occurrences**
- Example: `howManyTimes("aaaa", "aa")` → `3` (positions 0, 1, 2)
- Example: `howManyTimes("", "a")` → `0`
- Example: `howManyTimes("aaa", "a")` → `3`

#### 2. `strlen(String string)` → `int`
- Returns the length of the given string
- Example: `strlen("")` → `0`
- Example: `strlen("abc")` → `3`

#### 3. `flipCase(String string)` → `String`
- Flips lowercase characters to uppercase and uppercase to lowercase
- Non-alphabetic characters remain unchanged
- Example: `flipCase("Hello")` → `"hELLO"`
- Example: `flipCase("Hello!")` → `"hELLO!"`

### Main BookScan Method

The class should have a primary method (e.g., `scanByWordLength`) that:
- **Input:** A multi-line text (`String`) and a target word length (`int`)
- **Processing:**
  1. Split the text into lines (by `\n`)
  2. Split each line into words (by whitespace)
  3. Use `strlen` to filter words that match the target length
  4. Use `flipCase` to normalize text for case-insensitive comparison
  5. Use `howManyTimes` to count occurrences of each matching word in each line
- **Output:** A `Map<String, Map<String, Object>>` or similar structure containing:
  - For each unique word of the target length: its total count and the list of line numbers where it appears

### Edge Cases to Handle
- Empty text → return empty results
- No words matching the target length → return empty results
- Words appearing on multiple lines → aggregate line numbers correctly
- Case variations of the same word (e.g., "Hello" and "HELLO") should be treated as the same word
- Punctuation attached to words (decide how to handle: strip or include)

```java
/* @Authors

 * Student IDs: 150220079
 *
 * Generated by: Claude (LLM2) — Edited Prompt
 */
package phase_2.llm2.edited;

import java.util.*;

/**
 * BookScan analyzes text documents to find word occurrences by length
 * and track their line positions.
 *
 * <p>It processes multi-line text (lines separated by {@code \n}) to:
 * <ol>
 *   <li>Find all words of a specified length</li>
 *   <li>Count how many times each word appears (including overlapping occurrences)</li>
 *   <li>Track which line numbers (1-indexed) each word appears on</li>
 *   <li>Support case-insensitive matching via case transformation</li>
 * </ol>
 *
 * <p>Integrates three HumanEval utility methods internally:
 * {@link #howManyTimes}, {@link #strlen}, and {@link #flipCase}.
 */
public class BookScan {

    // =========================================================================
    // Task #18 — howManyTimes (substring counting with overlapping)
    // =========================================================================

    /**
     * Counts how many times {@code substring} appears in {@code text},
     * <strong>including overlapping occurrences</strong>.
     *
     * <pre>
     * howManyTimes("aaaa", "aa") → 3  (positions 0, 1, 2)
     * howManyTimes("",     "a")  → 0
     * howManyTimes("aaa",  "a")  → 3
     * </pre>
     *
     * @param text      the text to search within
     * @param substring the substring to find
     * @return the number of (possibly overlapping) occurrences, or 0 if either
     *         argument is {@code null} or {@code substring} is empty
     */
    public int howManyTimes(String text, String substring) {
        if (text == null || substring == null || substring.isEmpty()) {
            return 0;
        }
        int count = 0;
        int idx = 0;
        while ((idx = text.indexOf(substring, idx)) != -1) {
            count++;
            idx++; // advance by 1 to allow overlapping matches
        }
        return count;
    }

    // =========================================================================
    // Task #23 — strlen (string length)
    // =========================================================================

    /**
     * Returns the length of the given string.
     *
     * <pre>
     * strlen("")    → 0
     * strlen("abc") → 3
     * </pre>
     *
     * @param string the input string
     * @return the length of {@code string}, or 0 if {@code null}
     */
    public int strlen(String string) {
        if (string == null) {
            return 0;
        }
        return string.length();
    }

    // =========================================================================
    // Task #27 — flipCase (case inversion)
    // =========================================================================

    /**
     * Flips lowercase characters to uppercase and uppercase to lowercase.
     * Non-alphabetic characters remain unchanged.
     *
     * <pre>
     * flipCase("Hello")  → "hELLO"
     * flipCase("Hello!") → "hELLO!"
     * </pre>
     *
     * @param string the input string
     * @return the string with each letter's case inverted, or {@code null} if
     *         the input is {@code null}
     */
    public String flipCase(String string) {
        if (string == null) {
            return null;
        }
        StringBuilder sb = new StringBuilder(string.length());
        for (char c : string.toCharArray()) {
            if (Character.isLowerCase(c)) {
                sb.append(Character.toUpperCase(c));
            } else if (Character.isUpperCase(c)) {
                sb.append(Character.toLowerCase(c));
            } else {
                sb.append(c);
            }
        }
        return sb.toString();
    }

    // =========================================================================
    // Primary integration method
    // =========================================================================

    /**
     * Scans multi-line text for words of a given length. For each unique word
     * found (case-insensitive), it records:
     * <ul>
     *   <li><b>"count"</b> — total number of (overlapping) occurrences across
     *       all lines (as {@code Integer})</li>
     *   <li><b>"lines"</b> — sorted set of 1-indexed line numbers where the
     *       word appears (as {@code Set<Integer>})</li>
     * </ul>
     *
     * <p><b>Processing pipeline per line:</b>
     * <ol>
     *   <li>Split line into tokens by whitespace</li>
     *   <li>Strip non-alphanumeric characters from each token</li>
     *   <li>Use {@link #strlen} to filter tokens matching {@code targetLength}</li>
     *   <li>Use {@link #flipCase} to normalize to a lowercase key for
     *       case-insensitive grouping</li>
     *   <li>Use {@link #howManyTimes} to count occurrences of the word in the
     *       normalized line</li>
     * </ol>
     *
     * @param text         the multi-line text to scan (lines separated by
     *                     {@code \n})
     * @param targetLength the desired word length to search for; must be > 0
     * @return a map keyed by normalized (lowercase) words, each mapped to a
     *         {@code Map<String, Object>} with keys {@code "count"} and
     *         {@code "lines"}. Returns an empty map for null/empty text or
     *         non-positive target length.
     * @throws IllegalArgumentException if {@code targetLength} is negative
     */
    public Map<String, Map<String, Object>> scanByWordLength(String text, int targetLength) {
        Map<String, Map<String, Object>> results = new LinkedHashMap<>();

        if (text == null || text.isEmpty() || targetLength <= 0) {
            return results;
        }

        String[] lines = text.split("\n");

        for (int lineIdx = 0; lineIdx < lines.length; lineIdx++) {
            String line = lines[lineIdx];
            int lineNumber = lineIdx + 1; // 1-indexed

            // Normalize entire line for case-insensitive substring counting
            String normalizedLine = toLowerUsingFlipCase(line);

            // Split line into raw tokens by whitespace
            String[] tokens = line.split("\\s+");

            // Track which normalized words we've already counted on this line
            Set<String> processedOnLine = new HashSet<>();

            for (String token : tokens) {
                if (token.isEmpty()) {
                    continue;
                }

                // Strip punctuation so "hello," and "hello" are the same word
                String cleanWord = token.replaceAll("[^a-zA-Z0-9]", "");

                // Use strlen (Task #23) to check length
                if (strlen(cleanWord) != targetLength) {
                    continue;
                }

                // Normalize to lowercase using flipCase (Task #27) for grouping
                String key = toLowerUsingFlipCase(cleanWord);

                if (processedOnLine.contains(key)) {
                    continue;
                }
                processedOnLine.add(key);

                // Use howManyTimes (Task #18) to count occurrences in this line
                int occurrences = howManyTimes(normalizedLine, key);

                // Aggregate into results
                Map<String, Object> entry = results.computeIfAbsent(key, k -> {
                    Map<String, Object> m = new LinkedHashMap<>();
                    m.put("count", 0);
                    m.put("lines", new TreeSet<Integer>());
                    return m;
                });

                entry.put("count", (int) entry.get("count") + occurrences);

                @SuppressWarnings("unchecked")
                Set<Integer> lineSet = (Set<Integer>) entry.get("lines");
                lineSet.add(lineNumber);
            }
        }

        return results;
    }

    // =========================================================================
    // Internal helper
    // =========================================================================

    /**
     * Converts a string to lowercase by leveraging {@link #flipCase}.
     *
     * @param s the input string
     * @return the lowercase version, or {@code null} if input is {@code null}
     */
    private String toLowerUsingFlipCase(String s) {
        if (s == null) {
            return null;
        }
        StringBuilder sb = new StringBuilder(s.length());
        for (char c : s.toCharArray()) {
            if (Character.isUpperCase(c)) {
                sb.append(flipCase(String.valueOf(c)));
            } else {
                sb.append(c);
            }
        }
        return sb.toString();
    }
}
```

**Design decisions:**
- Instance methods (not static) — more natural OOP style for a class meant to be instantiated
- Main method is `scanByWordLength(String text, int targetLength)` as suggested in the prompt
- Returns `Map<String, Map<String, Object>>` with "count" (Integer) and "lines" (Set<Integer>) exactly as specified
- Uses `LinkedHashMap` to preserve insertion order for deterministic iteration
- Strips punctuation with `replaceAll("[^a-zA-Z0-9]", "")` before measuring length
- Created `toLowerUsingFlipCase()` helper that explicitly delegates to `flipCase` for case normalization
- Full JavaDoc with `@param`, `@return`, code examples in `<pre>` blocks
- Null-safe: returns empty results for null/empty text, null-checks on utility methods
- Per-line deduplication with `processedOnLine` HashSet to avoid double-counting
- Uses `computeIfAbsent` for cleaner map initialization
- `TreeSet<Integer>` for sorted, unique line numbers
