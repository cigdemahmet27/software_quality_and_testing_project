## LLM Response

Here is the `BookScan` class for package `phase_2.llm2`:

```java
/* @Authors
 * Student Names: Ahmet Enes Çiğdem, Ali Eren Çiftçi, Taha Çali
 * Student IDs: 150220079, 150220022, 150220050
 *
 * Generated by: Claude (LLM2) — Unmodified Prompt
 */
package phase_2.llm2.unmodified;

import java.util.*;

public class BookScan {

    /**
     * Find how many times a given substring can be found in the original string.
     * Count overlapping cases.
     * >>> howManyTimes("", "a")
     * 0
     * >>> howManyTimes("aaa", "a")
     * 3
     * >>> howManyTimes("aaaa", "aa")
     * 3
     */
    public int howManyTimes(String string, String substring) {
        int times = 0;

        for (int i = 0; i < string.length() - substring.length() + 1; i++) {
            if (string.substring(i, i + substring.length()).equals(substring)) {
                times += 1;
            }
        }

        return times;
    }

    /**
     * Return length of given string
     * >>> strlen("")
     * 0
     * >>> strlen("abc")
     * 3
     */
    public int strlen(String string) {
        return string.length();
    }

    /**
     * For a given string, flip lowercase characters to uppercase and uppercase to lowercase.
     * >>> flipCase("Hello")
     * "hELLO"
     */
    public String flipCase(String string) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < string.length(); i++) {
            if (Character.isLowerCase(string.charAt(i))) {
                sb.append(Character.toUpperCase(string.charAt(i)));
            } else {
                sb.append(Character.toLowerCase(string.charAt(i)));
            }
        }
        return sb.toString();
    }

    /**
     * Scans the given text and determines how many times words of the specified
     * length appear, and on which lines (1-indexed) they are found.
     *
     * @param text         the multi-line text to scan (lines separated by newline)
     * @param targetLength the desired word length to search for
     * @return a map where each key is a lowercase word of the target length,
     *         and the value is a WordResult containing occurrence count and line numbers
     */
    public Map<String, WordResult> scan(String text, int targetLength) {
        Map<String, WordResult> results = new LinkedHashMap<>();

        if (text == null || text.isEmpty()) {
            return results;
        }

        String[] lines = text.split("\n");

        for (int lineNum = 0; lineNum < lines.length; lineNum++) {
            String line = lines[lineNum];
            // Split on whitespace to extract words
            String[] words = line.split("\\s+");

            for (String word : words) {
                if (word.isEmpty()) {
                    continue;
                }

                // Use strlen to check the word length
                if (strlen(word) == targetLength) {
                    // Use flipCase to normalize: flip then lowercase gives us
                    // a consistent key regardless of original casing
                    String normalizedKey = flipCase(word).toLowerCase();

                    // Use howManyTimes to count occurrences of the word in the line
                    int occurrencesInLine = howManyTimes(line.toLowerCase(), normalizedKey);

                    if (!results.containsKey(normalizedKey)) {
                        results.put(normalizedKey, new WordResult(normalizedKey, 0, new ArrayList<>()));
                    }

                    WordResult result = results.get(normalizedKey);
                    result.count += occurrencesInLine;

                    // Track the line number (1-indexed) if not already added
                    int displayLineNum = lineNum + 1;
                    if (!result.lineNumbers.contains(displayLineNum)) {
                        result.lineNumbers.add(displayLineNum);
                    }
                }
            }
        }

        return results;
    }

    /**
     * Holds the result for a single word: its total occurrence count
     * and the list of line numbers where it appears.
     */
    public static class WordResult {
        public String word;
        public int count;
        public List<Integer> lineNumbers;

        public WordResult(String word, int count, List<Integer> lineNumbers) {
            this.word = word;
            this.count = count;
            this.lineNumbers = lineNumbers;
        }

        @Override
        public String toString() {
            return "WordResult{word='" + word + "', count=" + count +
                    ", lines=" + lineNumbers + "}";
        }
    }
}
```

**Design decisions:**
- Implemented all three utility methods (`howManyTimes`, `strlen`, `flipCase`) directly following the HumanEval canonical solutions as closely as possible
- Created a `WordResult` inner class to hold word, count, and line numbers
- Main method is `scan(String text, int targetLength)` returning `Map<String, WordResult>`
- Uses `flipCase` + `toLowerCase()` for case-insensitive normalization of word keys
- Uses `howManyTimes` to count per-line occurrences (not whole-text)
- Splits text on `\n` for lines, `\\s+` for words (whitespace only, preserving punctuation)
- Line numbers are 1-indexed
- Uses `LinkedHashMap` to preserve insertion order
