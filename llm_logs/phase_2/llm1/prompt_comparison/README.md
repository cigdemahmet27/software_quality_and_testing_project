# Phase 2 — LLM1 Prompt Comparison Logs

This directory contains logs comparing unmodified vs edited prompts for BookScan.

## Purpose

The project requires comparing:
1. **Unmodified & Combined:** Raw HumanEval prompt descriptions for #18, #23, #27 pasted together
2. **Edited & Combined:** Prompts refined/edited by the team to improve output quality

## Log Format

Each log file should contain:
1. **Prompt:** The exact prompt sent to LLM1
2. **Response:** The complete LLM1 response
3. **Notes:** Analysis of differences between the two approaches
